# 🌐 Desarrollo Web: HTML, CSS & JavaScript

Repositorio con los ejercicios prácticos y el proyecto final desarrollados durante el curso de **Desarrollo Web** dictado por la **Universidad Nacional de Salta (UNSa)**.

---

## 🛠️ Tecnologías y librerías utilizadas

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) Estructura semántica, meta tags viewport y accesibilidad
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) Flexbox, Media Queries (Mobile First), Google Fonts y paleta Cyberpunk/Dark
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) Funciones flecha, validaciones, operadores ternarios y manipulación del DOM
- ![EmailJS](https://img.shields.io/badge/EmailJS-FF6C37?style=flat&logo=mailgun&logoColor=white) Integración de servicio de mensajería asíncrona directa para el formulario
