Herramientas y Lenguajes de Programación

  1. C/C++
    • Nivel: Académico sólido / Fundacional.
    • Gestión manual de memoria (punteros, asignación dinámica con malloc/free).
    • Estructuras de datos fundamentales: listas enlazadas, colas, pilas y árboles.
    • Análisis de algoritmos (búsqueda lineal, binaria, ordenamiento) y optimización de rendimiento.
    • Lógica estructurada y comprensión de cómo interactúa el software directamente con el hardware y la memoria.
  2. JavaScript
    • Nivel: Práctico / Desarrollo web y backend.
    • Lógica asíncrona, manejo de eventos y manipulación del DOM
    • Desarrollo en el entorno Node.js para construir lógica de backend y APIs.
    • Integración de lógica de negocio (ej. sistemas de stock, validaciones y flujos de datos).
  3. Python
    • Intermedio / Scripting y resolución de problemas.
    • Sintaxis limpia y desarrollo rápido de scripts/automatizaciones.
    • Lógica algorítmica y modularidad.
    • Manejo de estructuras de datos nativas (diccionarios, listas, sets) y manipulación de archivos.
  4. HTML
    • Estructura semántica de documentos, accesibilidad básica, formularios, manejo del DOM.
  5. CSS
    • Maquetación moderna (Flexbox, CSS Grid), diseño responsivo (media queries), transiciones y estilización de interfaces limpias.
  6. Git
    • Control de versiones local: ramas (branching), resolución de conflictos, merge, rebase y trazabilidad de commits.
  7. Terminal / Línea de Comandos (Bash/Zsh):
    • Navegación por el sistema de archivos, ejecución de scripts, compilación desde terminal (gcc/g++), manejo de paquetes y configuración de entornos.
  8. GitHub
    • Repositorios remotos, trabajo colaborativo, Pull Requests, documentación con Readmes y uso de GitHub Codespaces para entornos en la nube.
  9. GitKraken
    • Gestión visual de árboles de Git, historial de ramas y agilización de flujos de trabajo en equipo.
  10. VS Code
    • Editor principal de código, configuración de extensiones para C/C++, JavaScript, linters, snippets y terminal integrada.
  11. Sistemas y Hardware
    • Conocimiento de arquitectura de hardware, mantenimiento, diagnóstico y optimización de sistemas.

Currently Exploring / Roadmap Técnico

  • Frontend moderno: React o TypeScript (el paso natural tras dominar JavaScript/HTML/CSS).
  • Backend & Arquitectura: Express.js (para armar APIs más robustas con Node) y profundización en Docker (contenedores básicos)
  • Bases de datos / Cloud: ORM/Query Builders (como Prisma o Sequelize) o despliegue básico (Render, Vercel, Railway).
  • PostgreSQL: Modelado relacional complejo, optimización de consultas, indexación y diseño de bases de datos robustas para aplicaciones escalables.
  • TypeScript: Incorporación de tipado estático sobre JavaScript para prevenir errores en tiempo de desarrollo y escribir código más predecible y mantenible.
  • Arquitectura de Software y Seguridad: Buenas prácticas de diseño modular (Clean Architecture / MVC), manejo seguro de datos, autenticación/autorización y protección contra vulnerabilidades web comunes.
  • Objetivo a mediano plazo: Consolidarme como Full Stack Developer, unificando el desarrollo de frontend moderno con backends escalables, seguros y conectados a bases de datos robustas.
